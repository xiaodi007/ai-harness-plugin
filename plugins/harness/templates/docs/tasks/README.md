# 任务卡

> 方法论 v1 §5。卡是工作记忆，不是事实源：结论必须回写 DECISIONS.md / docs/SYSTEM.md 等事实源。

- 每个非单步小改一张卡，复制 `_模板.md`，文件名 `YYYY-MM-DD-短标题.md`。已有本任务的卡就继续写，不另开。
- 状态：`active` 在做；`waiting` 等人；`done` 交付；`dropped` 放弃。
- 改成 `done` 时，harness 的 Stop 钩子会检查：契约、同类扫描、判定、证据等级、类别债节、别重做。缺了会拦一次，让 AI 补完。
  确实不适用时写一行 `校验豁免：理由`，豁免会被计数显示在开场摘要里。
- 维护者的结论写成 `维护者定（MM-DD）：…`；要维护者回答的写在交接节 `等你：…`，答完删。
- 每月把上月 `done/dropped` 的卡移到 `archive/YYYY-MM/`；单卡超过 30KB 就拆卡或把结论回写事实源。
